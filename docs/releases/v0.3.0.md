# Stratum 0.3.0

This release closes the DBeaver-inspired roadmap built on top of 0.2.0: fourteen phases of new
functionality, from connection portability and a PL/pgSQL debugger to a redesigned workbench and a
simpler appearance picker. See [Full changelog](https://github.com/LC-jhony/stratum/compare/v0.2.0...v0.3.0).

## Highlights

### Appearance

- **Settings ▸ Appearance** now has three controls: **Theme** (System / Light / Dark), **Palette**
  (Carbon / Min) and **File icons** (Dawn / Deep / Dim / You). The palette applies the variant that
  matches the theme — including OS changes in System mode — and file icons follow the same palette.
  Imported themes remain available from the command palette, the View menu and the status bar.
- Legible derived colours with WCAG contrast repair; themes are cached, sandboxed to their folders
  and survive a broken theme file without losing icons. All static product icons resolve.
- A Valet-inspired glass workbench with native-looking window controls preserved.

### Databases

- **PL/pgSQL debugger**: breakpoints, stepping, stack and variables for functions and procedures via
  `pldbgapi`, using two independent connections from the same data-source profile.
- **Structured connection diagnostics**: latency, server version and driver on success; a stable
  error code, failure stage and actionable hint on failure, with secrets redacted before IPC.
- **Savepoints and script commands** (`@set`, `@include`, `@export`), SQL files with safe save
  paths, schema-aware completion, safe grid edits, data import/export and a table designer.
- Global and per-connection **SQL variables**, a **driver manager**, portable connection settings.
- **Dashboard** with size/session metrics, **scheduled exports**, a **schema-aware AI assistant**,
  sessions, execution plans and saved queries.

### Platform

- Spatial cell viewer (WKT, GeoJSON, WKB) and declarative JDBC engine presets.
- More robust in-app updates: clearer failure reporting and atomic update metadata.
- One verification command (`npm run verify`) covering typecheck, architecture rules, tests and
  the production build; 672 tests passing at release time.

## Install

One-line installer on Debian/Ubuntu, Fedora/RHEL/openSUSE or other glibc systems:

```bash
curl -fsSL https://raw.githubusercontent.com/LC-jhony/stratum/main/scripts/install.sh | sudo bash
```

Or download the package for your platform below. Windows uses `stratum_setup.exe` (NSIS) or
`stratum_portable.exe`; macOS uses `stratum_universal.dmg` or `.zip` (macOS 13+); Linux offers
`.deb`, `.rpm` and AppImage. `SHA256SUMS` verifies every asset.

## Upgrade notes

- Desktop packages are **unsigned and unnotarized** — no signing secrets are configured. Windows
  SmartScreen and macOS Gatekeeper may warn on first launch.
- Linux packages target a conservative glibc baseline (`ubuntu-22.04`). The `.deb` no longer hard
  depends on `libxss1`; the installer keeps `chrome-sandbox` setuid root where needed.
- Settings, connections and sessions are preserved across the upgrade.
